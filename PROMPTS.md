# PROMPTS.md

# Uso de IA no Desenvolvimento

Este projeto utilizou IA como ferramenta de apoio para acelerar pesquisa, mantendo validação e decisão técnica sob minha responsabilidade.

A IA foi utilizada para:

- fluxo assíncrono;
- modelagem da API REST;
- criação e melhoria de testes automatizados;

---

# Prompts Utilizados

## 1. Modelagem da API

Prompt:

> Como modelar um endpoint POST /checkout em Node.js com validações de estoque e respostas HTTP adequadas?

Objetivo:

- estruturar contrato REST;
- validar uso de HTTP status;
- organizar resposta da API.

---


## 2. Processamento Assíncrono

Prompt:

> Como simular fila local ou ERP assíncrono sem infraestrutura externa usando memória ou mocks?

Objetivo:

- representar desacoplamento e processamento assíncrono.

---

## 3. Testes Automatizados

Prompt:

> Quais testes automatizados fazem sentido para um fluxo simples de checkout com validação de estoque e fila local?

Objetivo:

- aumentar confiabilidade;
- validar regras de negócio;
- evitar regressões.

---

# Validação Humana

Todo código, documentação e decisões arquiteturais geradas com apoio de IA foram revisados, adaptados e validados antes da entrega final.
